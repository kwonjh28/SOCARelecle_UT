# SOCARelecle UT Prototype

쏘카일레클 사용성 테스트용 웹 프로토타입입니다.

## Files

- `outputs/figma-prototype-embed/index.html`: 배포/공유용 테스트 페이지
- `outputs/figma-prototype-embed/assets/`: A/B 테스트와 정보 예측가능성 측정에 사용하는 이미지 자료
- `outputs/google-sheets-apps-script.gs`: Google Sheets 자동 저장용 Apps Script 코드
- `work/figma-prototype-embed/`: 작업용 원본 사본

## Notes
